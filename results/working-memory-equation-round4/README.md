# Working-memory score equation: continued research

The selected local equation matched **47.7%** of the app's scores on the fresh test, compared with **40.4%** for the unchanged previous best. Average displayed-score error was **0.683** units. These are equal-family averages; the reference answer is the middle of three app runs.

Software installation needs internet access; subsequent scoring runs locally. The formula still needs the specified local parser and text-measurement code. It was fitted to scores for the study's fixed grade-six reader profile; this version takes no learner-profile input. It is an approximation of this app procedure, not a validated measurement of human working memory.

Reference answers were collected under documented original and amended timeout/retry settings. The score calculation, equation predictions and statistical comparison stayed frozen; the report explains this operational change.

The final test did not select a different winner. All equation choices and predictions were saved before its reference scores were requested. Files and archive contents have recorded SHA-256 checksums in delivery-integrity.json and archive-verification.json.
